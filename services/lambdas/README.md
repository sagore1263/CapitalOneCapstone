## Services

- `services/get_users/lambda_function.py` → GET /users
- `services/get_user/lambda_function.py` → GET /users/{userId}
- `services/create_user/lambda_function.py` → POST /users
- `services/get_transaction/lambda_function.py` → GET /transactions/{transactionId}
- `services/create_transaction/lambda_function.py` → POST users/{userId}/transactions
- `services/health/lambda_function.py` → GET /health
